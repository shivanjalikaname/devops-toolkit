# DevOps Toolkit

A growing collection of small, practical DevOps tools: shell and PowerShell scripts,
Dockerfiles, CI/CD snippets, Kubernetes manifests and Terraform examples.
Each entry is self-contained, documented, and ready to copy into a real project.

## Index

| Date | Tool | Area | Description |
|------|------|------|-------------|
| 2026-10-26 | [http-healthcheck.sh](bash/http-healthcheck.sh) | Bash | Check HTTP endpoints with retries, timeouts and a CI-friendly exit code |

## Layout

```
bash/         Shell scripts for Linux/macOS hosts and CI runners
powershell/   Windows automation
docker/       Dockerfiles and compose examples
kubernetes/   Manifests, Helm snippets, kubectl helpers
terraform/    Small reusable modules and examples
ci/           GitHub Actions / GitLab CI workflows
python/       Python automation scripts
```
